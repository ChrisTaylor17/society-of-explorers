# SOE External Action Approval Matrix

Status: local operator control document. This document does not authorize any external action.

## Operating Rule

Local preparation is allowed: read-only research, local drafts, code changes, tests, screenshots, private docs, and private dashboards.

External action is blocked by default when it sends, publishes, deploys, charges money, creates checkout sessions, replays webhooks, applies production migrations, calls external AI/media providers, mutates a connected tool, contacts a person, or physically places material.

Approval must be specific to the action, scope, target system, final artifact, and timing. Broad permission such as "take over the computer" does not authorize an external mutation unless the current thread also approves the exact action.

## Standing No-Go Cases

- No live payments, checkout sessions, or webhook replay without an explicit mode-specific approval.
- No landlord contact or retail-space claim without final copy approval.
- No outreach from Gmail, Slack, SMS, social DMs, or browser automation without approved recipient, channel, and message.
- No Vercel deployment, Supabase production mutation, or Stripe live-mode action from broad verbal authority alone.
- No external AI/media provider call with private member, patron, lead, voice, or memory data without approved provider, route, input class, and purpose.
- No public copy that implies equity, debt, securities, dividends, guaranteed returns, secured lease, open location, or finalized buildout.
- No connected-tool mutation that exposes sensitive member, patron, lead, wallet, or relationship data beyond the approved scope.

## Operator Prompt

Before any blocked action, ask for the smallest approval that matches the matrix row. If Chris is unavailable, continue local preparation only and leave the blocked item in a draft or approval queue. Environment changes that affect production secrets must name the target variable and environment.

Use `/capital/approvals` as the private local checklist for review status. Its browser-local marks do not authorize deploys, sends, payments, migrations, connected-tool mutations, landlord contact, or physical placement.

Use `docs/soe-external-effect-route-inventory.md` before operator-driven route tests that might send, publish, charge, fulfill, mint, or call external providers.
