# Society of Explorers Operator System

This is the working compass for Codex automations and future build sessions.

## Operating Principles

- Privacy first: inspect and improve local systems freely, but do not send external messages, deploy, or mutate production data without explicit approval.
- Sovereignty always: every AI feature should improve member agency, data portability, consent, memory control, or community trust.
- Build the lived product: prefer usable member-facing surfaces over abstract strategy documents.
- Keep changes scoped: small verified improvements are better than broad rewrites that cannot be trusted.
- Tie magic to human value: voice, memory, agents, creator tools, and blockchain should make people feel more capable, not more watched.
