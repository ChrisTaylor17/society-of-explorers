# Root Kernel: first Scripture study

The Great Books library links to `/great-books/scripture/philemon`. It is a signed-out reading page: all 25 verses, both original publisher footnotes and questions to bring to a salon. The Scripture and publisher footnotes are in the reading column. The study column explains what the greeting says and compares a Nicene reading and a Biblical Unitarian reading without substituting either for the text.

The Scripture is [World English Bible Classic, Philemon 1](https://ebible.org/eng-web/PHM01.htm), edition `eng-web`. The [publisher FAQ](https://ebible.org/eng-web/webfaq.htm) confirms its public-domain/CC0 dedication and reserves the translation name for faithful copies. The local JSON comes from the publisher's [USFM archive](https://ebible.org/Scriptures/eng-web_usfm.zip). The verification script checks the exact archive and Philemon file hashes, removes markup for display, and compares all eight paragraph groups, 25 verses and both footnotes against the publisher's HTML. This changes formatting and placement of footnote markers only. The full source is available separately from the publisher.

The perspective notes are written for this study and link to the [Catholic Catechism, paragraphs 253–255](https://www.vatican.va/content/catechism/en/part_one/section_two/chapter_one/article_1/paragraph_2_the_father.html) and the [Biblical Unitarian statement of beliefs](https://www.biblicalunitarian.com/articles/what-do-biblical-unitarians-believe). This is one study shaped by the Root Kernel approach. No unpublished commentary corpus or AI generation is packaged here.

The [verification receipt](root-kernel-philemon-verification.json) binds the source comparison, offline Next build, lint, and six Chromium stories. The built route was statically rendered. Browser checks cover keyboard access from the signed-out library, exact Scripture and footnotes, separate sources and questions, verse and footnote navigation, 320px reading order, and reading with JavaScript disabled. The harness allowed only the owned local server and observed no API or external page request. Desktop and mobile screenshots were inspected. The server and browser were stopped and the port closed. No hosting change occurred.
