# Philemon remote salon

The signed-out Root Kernel study opens a five-part host guide. The suggested first meeting is a 45-minute online conversation for four to six readers. The group opens with a short prayer, reads all 25 verses aloud, compares interpretations of the greeting and discusses the appeal for Onesimus. Participants may listen or pass. Hosts share a private meeting link and keep recording and automated notes off. If the group wants to continue, the guide opens the weekly Circle form.

The host button presets Online. The public start page carries that choice through sign-in and asks the member to check hosting access before opening the form. Clearing the draft keeps the preset and empties the link field. The standard entry starts in person. A repeated format parameter uses the standard entry. The form keeps the existing review and confirmation steps for creating a listing. The host and current members can see the private meeting link in the Circle. The browser exercise saw the link appear after joining and disappear after leaving.

The built Chromium run checks the signed-out study, source text, accessible links, narrow viewport and online preset. The hosting fixture exercises the current browser form and handlers with synthetic identities and a disposable database. The guide and reading page used only the local build, with zero API requests. The test server, both browsers and the fixture database closed. The first meeting, video provider and hosted account flow still need pilot acceptance.
