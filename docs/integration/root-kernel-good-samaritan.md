# The Good Samaritan in Society of Explorers

The Great Books library offers Luke 10:25–37 as a second study in SoE’s Root Kernel section. It includes the passage, two readings of the lawyer’s question, three discussion prompts and a 45-minute online salon guide. The guide opens and closes with prayer and gives each reader time to speak or pass.

The packaged text uses the public-domain World English Bible Classic. An offline check compared all 13 verses, the continuation in verse 37 and both publisher cross-references against the publisher’s USFM file and HTML page. The study notes and guide were written for SoE. [Publisher’s Luke 10 edition](https://ebible.org/eng-web/LUK10.htm) · [Publisher reuse terms](https://ebible.org/eng-web/webfaq.htm)

## How to preview it

Open the Great Books library and select **Read and discuss the Good Samaritan**. The public study runs at /great-books/scripture/luke-good-samaritan. The complete text and guide render at phone width with JavaScript disabled. In the phone app simulations, the public study opened offline. A signed-in host can verify the same edition and choose it for the first meeting. A current member can open the assignment and return to the same Circle. The simulated Quest room checks Circle access again before displaying the bundled passage and its credits.
