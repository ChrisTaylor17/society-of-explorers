## System

- Background: true near-black charcoal `#080c0e`, never cream or softened gray.
- Text: parchment `#eee7d9`; controls use Geist; content/display text uses Cormorant Garamond.
- Accents: antique gold `#d0aa62`; mineral blue `#6b9bb5` is reserved for discovery/change actions.
- Container model: open canvas and page bands. Only the focused prompt, editable prompt, and auth/create surfaces receive thin frames.
- Motion: slow opacity and position drift that communicates depth; selected content becomes still and crisp. Respect reduced motion.
- Icons: thin 1.5px line icons, 16-19px, with no filled icon tiles.
