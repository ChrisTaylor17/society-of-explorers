## Current native email-account milestone

The registered app now offers explicit connection, existing-account email/password sign-in and restoration of a protected saved session. No Circle ID is needed to reach the verified member gate or own-contribution history. The older injected Circle path remains supported. Missing native configuration and unsupported platforms fail closed.

The actual official auth SDK runs behind a separate, pinned provider connection. Each explicit operation has a bounded lifetime and request budget; no constructor, subscription, reconnect or foreground return can refresh silently. A fresh provider check of the exact token precedes protected persistence, and every later member credential acquisition rechecks that token. SDK retry behavior is contained. Invalid replacement sign-in clears the previous account's in-memory authority before showing an error.
