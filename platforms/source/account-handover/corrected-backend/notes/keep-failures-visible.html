Keep the failures visible

current hypothesis open

A credible governor keeps failure modes visible and leaves room for a human stop. This page names that cut beside the Electronic Governor. It is not a complete taxonomy, not a product, and not a claim that every cascade was measured.

Keep visible

current Failure modes that stay namable are still available for review. Burying them to look finished is costume in the exhibition sense — an editorial pressure-test, not a census of incidents. The Electronic Governor already keeps a Keep-visible list in frame: automation without a governor, settle-without-enforceability, wrong-objective agents, and the false reading that “electronic” means government disappears. This note restates that posture. It invents no incident counts.

Human stop

current A named person or accountable institution must still be able to pause, override, or reject an automated disposition. Automation changes what arrives at the desk; it does not erase the desk. Acknowledge, hold, and log remain exhibition texture for where humans still sit — not a copied control-room screen, and not a universal interface.

Prompts, not a taxonomy

hypothesis Cascade. False plurality. Lost control. Ignored contingency. Those four are prompts for a failure review — non-exhaustive, not a ranked census, and not a finding that every cascade was measured. The hypothesis is the usefulness of keeping them namable. It is not a complete taxonomy of how governors fail.

Which first

open Which failure mode a given arrangement should examine first stays open. This page asserts no primary failure for all systems. Curiosity over prophecy includes leaving the order blank.

What would make this wrong

  • Wrong if “keep visible” is read as a complete incident database or a measured cascade count. None are stated.
  • Wrong if listing failure modes is taken as proof the system is safe.
  • Wrong if human stop is read as a universal interface or a copied HMI.
  • Wrong if this page is read as a product, a forecast, or an open intake.
  • Wrong if the physics-veto cut or the ledger costume cut is read as this page’s lead. Those stay on their own notes.

That humility beat is the one EXPLORE marks as what could make a frame wrong. Beat 02 on that page is what is already true. This note tries to stay inside that pair — curiosity, not prophecy.
