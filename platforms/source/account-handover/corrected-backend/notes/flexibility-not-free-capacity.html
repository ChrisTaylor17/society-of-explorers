Flexibility is not free capacity

current hypothesis open

Storage or flexibility beside a large draw can change which question you are asking. It does not mint free firm capacity. The companion cut — which queue the sentence is about — is generation queues are not load questions. This page stays on the next sentence: even when the question is load, flex is not a free substitute for firm deliverability.

Managed load and firm draw

current Firm worst-case draw and a managed-load or flexibility program are different questions. Worst-case firm draw asks what the site could take if the peak held and nothing were allowed to move — the draw a firm request has to treat as if it could stay. A managed-load or flex program asks what the site will draw when something can shift, cap, or respond. The distinction is operational: which question is on the table. It is not a count of how often one is accepted in place of the other, and it is not a finding that any tariff has been rewritten.

hypothesis Flexibility or storage beside a large load can change the interconnection question from that worst-case firm draw toward managed load. A battery, a controllable process, or an agreement to drop can be what lets the request be read as a shaped draw instead of a flat peak. “Can” is the claim. Not “does,” on every system, under every rule.

open How often that change is available, and under which tariffs and rules. Sharing a site with storage is not the same as having the study, the agreement, or the bill rewritten around a managed draw. This page does not survey tariffs. It does not name a region where the substitution is routine.

Not free capacity

hypothesis Flexibility is not free capacity. It is not a free substitute for firm deliverability. Storage beside a load can change the shape of a request. It does not mint firm capacity the system did not have to deliver, and it does not retire the question of whether that power is there when the site needs it. The caution is operational: do not hear “flex” as “the capacity was already there, at no cost.” This note did not measure megawatts. It names no credit, no queue position, and no clearing result.

On Power as a Primitive, Store already says buffers change response speed and do not erase the system. This note points that sentence at interconnection. A buffer can change which question is asked. It does not erase deliverability. That is a distinction inside this exhibition, not a grid-operations measurement.

What stays open

open How often flexibility changes an interconnection outcome, and under which tariffs and rules. Whether a program is studied as an assumption, written into an agreement, or only talked about. Whether it touches the study, the bill, or neither. Those stay open because they are local. This page will not fill them in.

No timetable sits under the hypothesis. No forecast of surplus, shortage, or a year when a queue clears. Curiosity over prophecy includes leaving the frequency blank.

What would make this wrong

  • Wrong if “storage beside load” is read as free firm megawatts, or as a forecast of headroom that will appear.
  • Wrong if the hypothesis is read as “flexibility always clears the queue,” or as a claim that interconnection has been solved.
  • Wrong if “different questions” is read as “managed load is easy,” or as “a firm study is pointless.” Both questions can still matter. They are still two questions.
  • Wrong if the caution is read as “storage never helps.” The hypothesis says flex can change which question is asked. The caution says that change is not free firm capacity.
  • Wrong if a reader takes a megawatt, a tariff, or a region’s rule from this page. None are stated.

That humility beat is the one EXPLORE marks as what could make a frame wrong. Beat 02 on that page is what is already true. This note tries to stay inside that pair — curiosity, not prophecy.
