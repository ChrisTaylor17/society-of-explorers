Firm connect vs faster path

current hypothesis open

Not every large load needs the same product on day one. Firm network service and a faster path that accepts curtailment or deferred upgrades are different contracts with different risk. One buys more certainty. The other buys earlier electrons with an asterisk. This page names the cut. It does not design a tariff, invent a FERC outcome, or measure megawatts.

Different products

current Firm network service and a faster path that accepts curtailment or deferred upgrades are different products with different risk. That cut is circulating in large-load process talk: one request asks the network to stand behind the draw; another asks to connect sooner and live with an asterisk — curtailment, or upgrades that are deferred. The claim is the distinction people are already using. It is not a count of how often either path is offered. It is not a finding that a region, a utility, or a proceeding has adopted a product this exhibition designed. This page names no tariff.

Certainty vs the asterisk

current One path buys more certainty. The other buys earlier electrons with an asterisk: curtailment, or the risk that an upgrade is deferred. That is an ops framing of the product cut. Certainty, here, means the kind of service the contract is trying to buy. It is not a measured probability, and it is not a price.

hypothesis How often that asterisk is priced honestly stays a hypothesis. Honest, in this sentence, would mean the curtailment or the deferred upgrade is visible as risk — not written as if the faster path were firm service under another name. This note does not know the rate, and it does not invent one. It did not read a tariff, and it did not price a contract.

Who holds the risk

open When the grid is stressed, who holds curtailment risk. The customer, the network, a program, someone the conversation never names — this page does not assign the holder. It stays open because the answer is local, and because this note did not invent an outcome that settles it. Curiosity over prophecy includes leaving the name blank.

Can the facility behave

hypothesis open Whether facility software and storage can actually behave under a non-firm asterisk. The hypothesis is the shape of the question: a contract that accepts curtailment, or that defers an upgrade, still has to be a site that can follow it — drop, hold, or wait — when the asterisk is called. “Can” is not “does.” The open part is the answer for any real facility. This page did not test controls, storage, or a site. It is not a product claim, and it is not a measured finding.

Not the greener question

The interesting ops question is product risk, and who holds the asterisk when the grid is stressed. It is not which path is greener. A faster path is not a climate ranking on this page, and firm service is not one either. This note does not score either product. The cut stays on the contract, and on whether the site can behave under stress.

What would make this wrong

  • Wrong if “connect faster” is read as the same product as firm forever.
  • Wrong if this page is read as SoE having designed a tariff or interconnection product.
  • Wrong if a reader takes a FERC outcome, tariff number, megawatt, ELCC percentage, or ISO statistic from this page. None are stated.
  • Wrong if who holds curtailment risk is treated as settled here. That stays open.
  • Wrong if facility software and storage “can behave under the asterisk” is read as a measured finding or a product claim. That stays open, and the question stays a hypothesis.
  • Wrong if the page is read as answering which path is greener. That is not the interesting ops question here.
  • Wrong if non-firm or faster paths are dismissed as never useful. The cut is different products and different risk, not “faster is fake.”

That humility beat is the one EXPLORE marks as what could make a frame wrong. Beat 02 on that page is what is already true. This note tries to stay inside that pair — curiosity, not prophecy.
